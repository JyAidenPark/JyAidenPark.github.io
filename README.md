# Jun Young (Aiden) Park — Academic Website

[Personal website](https://jyaidenpark.github.io/)

## Content management

- Home and contact links: `_pages/about.md`
- Publications: `_bibliography/papers.bib`
- Chip Gallery: `_pages/projects.md`
- CV: `_data/cv.yml`
- Site settings: `_config.yml`
- Personal images: `assets/img/fix/`

Changes to the main branch are built by GitHub Actions and deployed to GitHub Pages.
